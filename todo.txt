Last updated September 28, 2026. Details for each item are in docs/RUNBOOK.md and docs/DECISIONS.md.


HOW IT RUNS NOW

- Every day at 09:00 UTC, GitHub Actions runs "Daily run". It reads the news feeds, groups the stories,
  explains the big ones, picks the day's word, and saves it all in the database.
- The site reads the database, so it updates by itself. Nobody deploys anything day to day.
- Each run ends by deleting world data older than 30 days, so the free database never fills up.
- If a run fails, GitHub emails the repo owner and the site keeps showing the last good day.
